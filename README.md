# 主軸元件照片蒐集平台

9 廠受補貼機構主軸元件（破壞前／破壞後）照片蒐集。現場人員用手機開網址即可拍照上傳，**不需要任何帳號登入**；照片自動命名後存入你的 Google Drive，紀錄寫入 Google 試算表。

```
手機瀏覽器 ──► GitHub Pages (index.html，純前端)
                      │  POST JSON（照片 base64 + 中繼資料）
                      ▼
            Google Apps Script 網頁應用程式 (apps-script/Code.gs)
                      │
          ┌───────────┴────────────┐
          ▼                        ▼
   Google Drive                Google 試算表
   主軸元件照片蒐集/             主軸元件照片紀錄
     P01_○○廠/廢電冰箱/*.jpg       照片（每張一列）、設定（JSON）
```

## 一、部署後端（Google Apps Script，約 5 分鐘）

1. 用你的 Google 帳號開啟 <https://script.google.com> → **新專案**。
2. 把專案左上角名稱改成「主軸元件照片平台」。
3. 刪除編輯器裡預設的 `function myFunction(){}`，把本 repo `apps-script/Code.gs` 的**全部內容**貼上。
4. 修改最上方的 `ADMIN_CODE`（管理密碼，用來改設定、刪照片）。`UPLOAD_CODE` 留空＝任何人開網址就能上傳；要擋陌生人就填一組通行碼發給現場人員。
5. 上方函式選單選 **`setup`** → 按 **執行** → 彈出授權視窗 → 選你的帳號 → 「進階」→「前往…（不安全）」→ 允許。執行完成後「執行紀錄」會印出 Drive 資料夾與試算表網址。
6. 右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（一定要選這個，現場人員才不用登入）
   - 按「部署」，複製 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。

> 之後若修改 Code.gs，要再「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」，網址不變。

## 二、把後端網址填進前端

編輯 `index.html`，找到 `<script>` 開頭這一行：

```js
const API_URL = '';
```

把網址貼進引號內並 commit。GitHub Pages 約 1 分鐘後更新。

（測試階段也可以不改檔案：開啟網頁後在「首次設定」卡片貼上網址，只會記在那台裝置。）

## 四、使用

| 頁面 | 誰用 | 內容 |
|---|---|---|
| 拍照上傳 | 現場人員 | 選機構 → 家電／資訊 → 廢物品 → 下方自動列出主軸元件，每個元件各有「破壞前／破壞後」格子，點一下開相機。可多選。 |
| 照片總覽 | 所有人 | 依機構／類別／物品／階段篩選，點縮圖開 Drive 原圖；匯出 CSV；開啟 Drive 資料夾（右鍵→下載＝整包 ZIP）。管理者登入後可刪除。 |
| 進度 | 所有人 | 機構 × 主軸元件矩陣，顯示「破壞前 / 破壞後」張數。 |
| 設定 | 管理者 | 9 廠名稱與代碼、各類別廢物品與主軸元件清單、破壞方式提示、檔名規則、縮圖大小。 |

檔名預設規則：`{機構代碼}_{類別}_{物品}_{元件}_{階段}_{流水號}.jpg`
例：`P03_家電_廢電冰箱_廢壓縮機_破壞後_20261118-0007.jpg`。流水號「日期-當日序號」由後台在上傳時自動配發。

主軸元件預設清單依環境部資源循環署《應回收廢棄物回收清除處理稽核認證作業手冊（廢電子電器暨廢資訊物品類）》115 年 4 月版整理，可在設定頁調整。

## 注意事項

- 照片預設會設成「知道連結者可檢視」（`SHARE_PUBLIC = true`），前端才顯示得出縮圖。若不想這樣，改成 `false`，縮圖會顯示不出來，但 Drive 裡的檔案與總覽的文字紀錄都正常。
- 任何人拿到網址都能看到照片總覽與進度；要限制，可在 Code.gs 的 `list` 分支加上 `requireAdmin_(req)`，並在前端總覽頁要求先登入管理者。
- Apps Script 免費額度：每天約 6 小時執行時間、單次請求 50 MB；一張 1920px 照片約 0.3–0.5 MB、上傳 1–3 秒，足夠數千張使用。
- Drive 空間用的是你 Google 帳號的配額（免費 15 GB）。
